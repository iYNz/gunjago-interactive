# 군자디지털과학고등학교 인터랙티브 미디어 공간 구축 계획

복도 바닥 프로젝션 + 교실 LED 미디어월 구성안. 정적 웹 덱이며 빌드 단계가 없다.

## 배포

Netlify — 이 저장소 루트를 그대로 publish 한다 (`netlify.toml`, `publish = "."`).

## 조작

| 키 | 동작 |
|---|---|
| `←` `→` · `Space` | 슬라이드 이동 |
| 숫자 입력 (우하단) | 해당 장으로 워프 |
| 휠 | 07p 복도 전후 이동 · 08p 관람 지점 이동 |

1920 × 1080 고정 캔버스를 레터박스로 스케일한다. **데스크톱 전용**이다.

## 이 폴더는 생성물이다

원본은 `../deck` 이고, `tools/build_deploy.py` 가 실제로 참조되는 파일만 추려
여기에 복사한다. 영상은 배포본에서만 1,440px · CRF 33 으로 다시 굽는다
(원본에 58 Mbps 짜리가 섞여 있어 그대로 올리면 저장소가 300MB 가 된다).

직접 고치지 말고 `deck/` 를 고친 뒤 다시 빌드할 것.
