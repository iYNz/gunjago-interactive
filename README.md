# 군자디지털과학고등학교 인터랙티브 미디어 공간 구축 계획

복도 바닥 프로젝션 + 교실 LED 미디어월 구성안. 정적 웹 덱이며 빌드 단계가 없다.

확정 전 **공간 구성 가이드**다. 두 공간에 어떤 콘텐츠가 들어가고 실제로 어떻게
보이는지까지만 담았고, 사양 · 일정 · 견적은 현장 실측 이후에 붙인다.

## 배포

Netlify — 이 저장소 루트를 그대로 publish 한다 (`netlify.toml`, `publish = "."`).

## 조작

| 키 | 동작 |
|---|---|
| `←` `→` · `Space` | 슬라이드 이동 |
| 우하단 숫자 입력 | 해당 장으로 워프 |
| 휠 | 07p 복도 전후 · 08p 관람 지점 이동 |

1920 × 1080 고정 캔버스를 레터박스로 스케일한다. **데스크톱 전용**이다.

## 이 폴더는 생성물이다

원본은 `../deck` 이고 `tools/build_deploy.py` 가 만든다. `index.html` 이 실제로
로드하는 css/js 만 따라가고, 거기서 참조되는 에셋만 복사한다 — 작업 중 쌓인
시안 파일은 자동으로 빠진다.

영상은 배포본에서만 1,440px · CRF 33 으로 다시 굽는다. 원본에 9초짜리 65MB
(58 Mbps) 가 섞여 있어 그대로 올리면 저장소가 300MB 가 된다. 덱 타일은 400px,
라이트박스도 1920 이하라 그 비트레이트는 화면에 남지 않는다.

**직접 고치지 말고 `deck/` 를 고친 뒤 다시 빌드할 것.**
